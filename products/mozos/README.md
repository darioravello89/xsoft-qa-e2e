# Mozos Flutter

Estado: **`planned`**. App Flutter separada, pendiente de incorporar repositorio/APK QA y contrato funcional. No se asume que XMozo Angular o XPortal Mobile sean esta aplicación.

El motor previsto es Maestro para Android. La automatización se ejecutará contra un APK QA en emulador o dispositivo dedicado, con identificadores accesibles reales y backend de pruebas. No se instala Maestro ni un emulador como requisito de la primera entrega XGestion.

La estructura reserva `scenarios/`, `suites/`, `resources/` y `docs/`. No hay flujos ficticios que devuelvan éxito. Ver [onboarding](docs/onboarding.md).
